# Certificate Authority Service

Certificate Authority Service is a highly available, scalable Google Cloud service that helps you simplify, automate, and customize the deployment, management, and security of private certificate authorities (CA).

## Supported Operations
- **CA Pools**
- **CAs**
- **Certificates**

## Example API Path
`/v1/projects/{project}/locations/{location}/caPools`

## Persistence Status
WAL-backed
