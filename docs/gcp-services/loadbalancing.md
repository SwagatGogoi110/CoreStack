# Cloud Load Balancing

Google Cloud Load Balancing is a fully managed, software-defined, distributed systems service for all your traffic.

## Supported Operations
- **Forwarding Rules**
- **Target Proxies**
- **Url Maps**
- **Backend Services**

## Example API Path
`/compute/v1/projects/{project}/global/forwardingRules`

## Persistence Status
WAL-backed
