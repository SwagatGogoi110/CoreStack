# Cloud Spanner

Cloud Spanner is a fully managed, scalable, relational database service that provides ACID transactions and SQL semantics at global scale.

## Supported Operations
- **Instances**: Create, List
- **Databases**: Create, List
- **Sessions**: Create, Delete
- **ExecuteSql**: Stub implementation

## Example API Path
`/v1/projects/{project}/instances`

## Persistence Status
WAL-backed
